工具介紹隱私權政策服務條款

Clip Schedule Publisher

個人使用的本機影片上傳與排程工具，透過 YouTube Data API 操作使用者授權的頻道。本工具並非 Google 或 YouTube 的官方產品。

操作流程

  1. 提供本機 index.html 或 preview.html 與已完成剪輯的 MP4。
  2. 整理 1–5 支影片的標題、相關 hashtag、來源連結與原片時間。
  3. 選擇發布日期及兒童內容設定，安排台灣時間 08:00、12:00、18:00、21:00、23:00 的適用時段。
  4. 使用者檢查整批內容與頻道，明確確認後才執行 API 上傳。
  5. 檢查上傳結果並保存本機紀錄，協助避免重複上傳。

目前狀態

本工具供開發者本人使用，沒有公開註冊或線上登入服務。OAuth 授權與頻道識別已測試；實際影片上傳尚未完成測試，API 稽核尚未完成。排程功能的程式已準備，但公開發布能力須待稽核及實際測試確認。

開始使用前請閱讀並同意隱私權政策與服務條款。授權在 Google 的頁面進行，不需要將 Google 密碼交給本工具。
