工具介紹隱私權政策服務條款

隱私權政策

Clip Schedule Publisher · 文件草稿 · 2026-10-04

範圍與資料用途

這是開發者本人使用的本機工具。工具讀取使用者提供的影片、預覽 HTML、來源資料與發布計畫，用於準備及執行經確認的影片上傳。透過 YouTube API 讀取授權頻道資訊、影片標題與狀態、上傳播放清單項目，用於確認頻道、查驗結果及處理中斷。

OAuth 權限

工具要求 youtube.upload（上傳影片）與 youtube.readonly（讀取帳戶、頻道與影片資訊）。Google 的授權畫面可能使用較概括的權限文字；使用者應閱讀該畫面再決定授權。工具不收集 Google 帳戶密碼。

本機保存

OAuth 權杖、頻道設定與上傳帳本保存於使用者電腦的 %LOCALAPPDATA%\CodexYouTubeShorts，或明確指定的設定目錄。影片與發布計畫位於使用者工作資料夾。權杖可在有效時更新，供後續已授權操作使用。資料目前沒有自動到期刪除機制，須由使用者管理；此限制仍需在稽核前評估及改善。

對外傳送與第三方

經確認上傳時，影片、標題、說明、發布時間與相關設定會傳送至 Google／YouTube。讀取狀態時也會與 Google API 通訊。工具沒有自建的雲端資料庫或廣告分析服務，不出售資料。

此流程由 Codex 協助執行。使用者提供到聊天的文字、影片資訊及工具輸出可能由 OpenAI 依使用者帳戶設定處理；請勿把 OAuth 權杖、用戶端密碼或 Google 密碼貼入聊天。網站若以 GitHub Pages 託管，其提供者也會依自身政策處理網站連線資料。本靜態網站沒有自行設定分析追蹤器或表單。

撤銷授權與刪除

可隨時在Google 帳戶第三方存取設定撤銷本工具授權。撤銷不會自動移除本機檔案。

停止工具後，使用者可手動刪除上述設定目錄中的 token.json、config.json、ledger.json，以及工作資料夾的發布計畫與結果檔案。刪除帳本將失去重複上傳檢查紀錄，重新使用前須核對 YouTube Studio。備份副本亦須另行移除。本機刪除不會刪除已上傳影片；影片可透過 YouTube Studio 管理。Codex 聊天資料須透過該服務的資料管理功能另行處理。

相關政策

本工具使用 YouTube API Services。請參閱Google 隱私權政策、YouTube 服務條款及OpenAI 隱私權政策。
