服務條款

使用範圍

本工具目前供開發者本人於本機使用，免費，沒有公開註冊服務。它透過 YouTube API Services 操作使用者授權的頻道；使用者亦受YouTube 服務條款約束。

使用者確認

使用者應確認影片使用權、標題、來源標示、兒童內容設定、發布日期與頻道。標示來源不等同取得著作權授權。整批發布計畫須經明確確認後執行。

功能與限制

時間安排基於內容的編輯判斷，沒有保證觀看次數或觀眾喜好。網路、Google 配額、影片處理或平台限制可能使上傳與排程失敗。OAuth 授權不代表 API 稽核通過。目前實際上傳測試與 API 稽核尚未完成，公開發布能力尚未驗證。

資料與停止使用

請閱讀隱私權政策了解本機保存、第三方處理、撤銷授權與刪除方式。使用者可停止執行工具並撤銷授權。上傳中斷後應檢查紀錄及 YouTube Studio，避免重複上傳。

變更與聯絡

工具範圍或資料處理方式變更時，應更新相關文件並重新取得所需同意。維護者：Jerry Chen，公開聯絡方式待本人確認。
